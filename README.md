# 전기차 배터리 SOC 예측 재검증 (2021 → 2026)

2021년 전자공학 졸업 프로젝트(2인 팀)에서 만든 배터리 SOC 예측 모델은 무작위 8:2 분할에서 R² 0.9999를 기록했습니다.
회귀 문제로는 지나치게 높은 값이어서, 2026년에 원본 데이터부터 개인적으로 다시 검증했습니다.

## 결론

R² 0.9999만으로는 미래 예측 능력을 입증할 수 없었습니다.
결측 패턴과 시간만으로도 높은 R²가 재현되고, 곡선별로 보면 현재 값을 그대로 쓰는 예측보다 오차가 컸습니다.

## 확인한 것

| 단계 | 결과 |
|---|---|
| 2021 코드 재현 (seed 10개) | 무작위 8:2 R² 0.99967~0.99994, 마지막 100행 R² 0.7903~0.7915 |
| 요인 분해 | 결측 여부 1개 변수만으로 R² 0.759, 시간 변수를 더하면 R² 0.992 |
| 시간순 5-fold 검증 | R² 평균 0.963 → R² 수치만으로는 모델 간 차이를 판단할 수 없음 |
| 곡선별 평가 | 12개 곡선 모두 RF 오차(MAE)가 '현재 값 그대로' 예측보다 큼 |
| 단순 기준 방법 비교 | 4개 예측 시점 중 3개에서 단순 기울기 연장이 최소 오차 |
| 주행거리 환산식 검산 | 383km ÷ 60 × SOC → SOC 100%에서 638.33km, 1.6667배 과대 계산 (분모 100으로 수정 시 383.0km) |
| 원본 xlsx 점검 | MD5로 내용 중복 파일 3쌍 확인, 단위가 다른 하이브리드 파일은 병합에서 제외 |

99.2%(0.992 ÷ 2021 R²)는 R² 비율이며 원인별 기여율이 아닙니다.

## 데이터

- 선행 연구 논문의 그래프를 수치화한 구간별 직선 데이터입니다. 실제 차량 BMS 로그가 아닙니다.
- 계열마다 차량·장치·실험 조건이 다릅니다. 출처는 `outputs/Q0_데이터_출처표.csv`에 정리했습니다.
